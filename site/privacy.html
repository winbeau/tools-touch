隐私政策

生效日期：2026 年 9 月 5 日 · 适用版本：Tools Touch 0.2.1

Tools Touch 是由 GitHub 用户 winbeau维护的 Windows 桌面应用。本政策说明当前版本访问、使用、保存和共享数据的方式。Google 授权界面中的应用名称可能显示为 tools-touch。

1. 应用账号与 Gmail 权限

你通过 Google 授权登录，应用读取 Gmail 账号邮箱地址，将其作为本机应用账号与投递邮箱。我们不要求提供 Google 密码。安装包中的桌面客户端配置只标识应用，不包含任何用户的 Gmail 登录凭据。

gmail.send 用于在你确认后发送所选邮件，包括收件人、主题、正文和你添加的附件。gmail.readonly 用于核对发送结果及同一邮件线程的回复状态，读取相关邮件标识、时间、标签和必要邮件头。这些权限用于邮件功能，并非仅为识别登录身份。

当前版本不将 Gmail 收件内容提供给模型分析，不提供自动批量发送功能。授权范围本身允许读取邮箱；实际请求限定于账号识别、发送核对和回复状态功能。

2. 本地保存的数据

应用在当前 Windows 用户的本地应用数据目录保存个人资料、导师与论文资料、分析结果、草稿、发送记录、设置和模型会话。Gmail 刷新凭据通过 Windows DPAPI 保护，访问令牌保存在进程内存中。模型服务商凭据由应用内的模型运行组件保存在本机专用目录，请同时保护好 Windows 账号与设备。

应用诊断日志保留 14 天，仅记录运行阶段与错误分类，不记录邮件正文、密钥或授权码。日志不会自动上传；只有你主动导出并分享时，接收方才会获得该文件。

3. 对外连接与数据共享

邮件授权、账号查询、发送和状态核对直接连接 Google 服务。当前版本没有由维护者运营的邮件中转服务器、云端账号数据库或资料同步服务。

你启动研究、分析或起草任务时，所需的用户请求、确认过的个人资料、导师信息、论文文本和研究上下文可能发送给你配置的模型服务商。搜索词可能发送给配置的检索服务，公开论文与网页请求连接相应来源站点。这些服务按各自政策处理请求；请在使用前了解所选服务商的条款。

维护者不销售 Google 用户数据，不将 Google 用户数据用于广告投放、信用评估或训练通用人工智能模型。本应用对从 Google API 获得的信息的使用和向其他应用的转移，将遵守 Google API Services User Data Policy，包括 Limited Use 要求。

4. 保留、撤销与删除

研究资料和账户状态保留在本机，直到你删除。卸载默认保留这些资料。若需全部清除，先退出应用，再删除 %LOCALAPPDATA%\ToolsTouch 文件夹；这会同时删除该 Windows 用户的本地资料、草稿、日志和保存的凭据，请先备份需要保留的内容。

你也可以在 Google 账号的第三方连接管理 中撤销 Tools Touch 的访问权限。撤销授权不会自动删除本地资料；删除本地资料也不会删除已发送到 Gmail 或收件人的邮件。模型服务商保存的数据应通过该服务商提供的渠道处理。

5. 网站、联系与政策更新

本介绍网站由 GitHub Pages 托管，没有应用设置的广告、分析脚本或登录表单。GitHub 可能按其 隐私声明处理访问请求信息。

如需帮助或对本政策有疑问，请通过 项目支持页面联系维护者。公开反馈时请不要提交密钥、授权码、个人简历或邮件正文。功能和数据处理方式变化时，我们会更新本页与生效日期。
