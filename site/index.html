WINDOWS · 研究与投递

发现导师，整理研究，
认真写好每一封邮件。

Tools Touch 将导师资料、论文分析和邮件草稿放在同一个桌面工作台。使用自己的 Gmail 登录，审核草稿后再发送。

下载 Windows 测试版使用说明

Windows x64 · 安装包内置运行环境与 Google 应用登录配置

当前为测试版。Google 应用仍处于测试状态，Gmail 公开授权审核尚未完成。目前不能保证任意 Google 账号都能登录。下载程序无需自行申请 OAuth 客户端或导入 JSON。
01 / 发现

保留来源的研究

整理导师主页、论文和公开联系方式，在来源证据的基础上进行分析。

02 / 起草

选择自己的模型

在桌面界面配置 OpenAI、DeepSeek、Claude、GLM 等服务商。相关账号或 API 用量由所选服务商管理。

03 / 投递

审核后再发送

登录 Gmail 后作为应用账号与发件邮箱。人工检查收件人、正文和附件，再确认发送并核对回复状态。

资料保存在你的电脑上

当前版本没有应用自建的云端资料同步服务。Gmail 登录凭据由 Windows 加密保存；你启动的研究任务会将所需资料发送给自己配置的模型或检索服务。
