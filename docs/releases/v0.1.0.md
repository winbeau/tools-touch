# Tools Touch v0.1.0 · Windows 安装版

首个 Windows 安装版，包含导师发现、论文阅读与分析、CV 确认、邮件草稿、Gmail 人工发送及回复同步的基础实现。

## 下载与安装

下载 **ToolsTouch-Setup-0.1.0-win-x64.exe**，双击安装。安装包内置 .NET、Node.js 和 Pi 依赖，无需另装运行环境。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\ToolsTouch`，无需管理员权限，提供开始菜单入口和可选桌面快捷方式。

升级时先退出 Tools Touch，再运行新安装器。在 Windows“已安装的应用”中可卸载；研究库、CV、草稿和账户资料保留在 `%LOCALAPPDATA%\ToolsTouch`。

当前 EXE 未做代码签名，Windows 可能显示“未知发布者”。可使用附件中的 `SHA256SUMS.txt` 核对下载文件。

## 本版内容

- 六个 WPF 页面、SQLite 本地研究库、论文阅读和 CV 版本确认。
- 复用 Pi 的 OpenAI 登录和研究流程，Gmail 采用独立授权与 Windows DPAPI 凭据存储。
- 修复 Pi 连接后退出卡死、取消草稿选择留下旧正文、筛选导师后详情残留。
- 新增可重复的安装器构建、安装/修复/卸载检查及 Windows 桌面回归脚本。

## 验证与当前边界

核心回归、AgentHost 7 项测试和 Windows 原生 7 组检查通过。安装器检查结果见附件 `installer-test-results.json`；原生检查结果见 `windows-test-results.json`。测试使用合成资料和邮件替身，没有发送真实邮件。

真实 OpenAI/Gmail 登录、Brave API 检索、真实模型工具流程与邮件收发的完整验收仍待完成。首次使用需要自行配置账号及 API；自动化检查通过不代表上述流程已验收。

源码、配置说明和详细验收记录见仓库 README、`docs/WINDOWS.md` 和 `docs/ACCEPTANCE.md`。
