# Tools Touch v0.3.0 测试版

建议安装 [v0.3.1 修复版](https://github.com/winbeau/tools-touch/releases/tag/v0.3.1)：修复 Windows 启动与备份问题，并完成原生安装、升级及卸载检查。

本版完成新架构的 37 个实施工作包，包含学校／学院窗口规则、导师目录与身份证据、论文阅读与评价、画像统计、两级推荐、邮件草稿与发送状态、申请记录，以及自定义表格／字段／关联／视图／导入／全量导出与恢复。

便携包新增 Windows Python runtime 和锁定的 collector 生产依赖；BUILD-MANIFEST.json 会逐文件校验 .NET、Node、AgentHost 和 Python 运行时。当前发布资产提供 Windows x64 便携 ZIP 和 `ToolsTouch-Setup-0.3.0-win-x64.exe` 安装器；安装器由 Windows Python 与 Inno Setup 6.7.3 构建，未签名。

验证包括 Node 16 项、baoyan-cli 9 项、collector-host 8 项、C# Core 可执行回归、六个 C# 工程 Release 编译、15,285 个便携包文件哈希、ZIP 完整性、AgentHost protocol v2 / output schema 2 / 40 providers 握手，以及 U01—U11 验收矩阵检查。

本版没有使用真实账号、Brave 凭据或真实来源范围，也没有发送真实邮件。U01—U11 的真实流程均保持 `NotVerified`；安装器构建和静态校验已完成，安装／升级／卸载生命周期因当前 Windows 用户已有 0.2.2 安装而未执行，需要单独 Windows 测试用户完成。来源范围和首批校院名单仍待确定。
