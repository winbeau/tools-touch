# Tools Touch v0.3.2 测试版 · 研究与申请工作台

下载 `ToolsTouch-Setup-0.3.2-win-x64.exe` 安装或升级。Windows x64，当前用户安装，无需管理员权限；内置 .NET、Node／Pi 和 Python collector。便携版为 `ToolsTouch-win-x64-v0.3.2.zip`。

## 界面与交互

- 全部 11 页采用统一浅色工作台，保留青绿色强调色。七组左侧导航替代顶部拥挤标签，导师详情通过列表进入并可返回。
- 统一按钮层级、输入、表格、焦点、禁用、校验与状态提示；导航使用矢量图标。表格保持原生虚拟化，表单可独立滚动。
- 邮件工作区分开草稿列表、正文、附件及发送操作；补充空选择、加载、失败和只读说明。同步与发送时临时锁定编辑，保留待保存内容。
- 记录器的筛选、保存视图、导入和表结构配置收进折叠区；资料与设置分为三个局部标签；导师目录提供论文、评价和采集覆盖子页。
- 修复刷新申请及记录表单丢失选择、筛选、保存视图或未保存编辑的问题。页面切换保留实例和滚动位置，所有原有 54 个界面命令入口仍可达。
- 添加 PerMonitorV2 支持。没有引入新的 UI 框架或包依赖，也没有新增数据库迁移。

## 验证与安全边界

界面改造已通过 C# Core 可执行回归和 23 组 Windows 原生自动检查，零 WPF 绑定错误。覆盖 11 页、详情及设置子页、三种窗口大小、键盘焦点、输入校验、未保存编辑、加载和 Unknown 只读状态。100%／125%／150% 使用隔离原生窗口的 DPI 变更消息验证，WPF 实际报告对应 DPI；真实跨显示器人工拖动仍未验证。

发送仍要求用户确认具体邮件快照，Unknown 不会自动重试。自动检查使用隔离合成资料和模拟授权，没有发送真实邮件。安装器未签名；Google 审核、真实账号与来源的完整业务验收仍未完成。

升级前退出 Tools Touch。安装程序默认保留原有工作区；卸载保留用户资料。发布附件中的安装、桌面及 CI 检查结果与 SHA-256 校验文件记录最终交付验证。
