# Tools Touch v0.2.0 测试版

此测试版需要先导入有效 Google 桌面 OAuth 客户端配置，才能完成首次登录。

首次使用 Gmail 登录后进入工作台；同一 Gmail 作为应用账号和投递邮箱，登录状态加密保存。打开程序自动加载组件，显示加载阶段与进度条。设置页新增统一的模型账户配置，修复 OpenAI 授权流程卡住、后续点击提示 RUN_BUSY 的问题。

- OpenAI · ChatGPT 账户支持自动打开浏览器、设备码授权和取消重试；OpenAI API、DeepSeek、Claude、GLM 等从实际组件读取授权方式与模型，研究任务使用所选服务商。
- API Key 使用密码输入框，提交后清空，不写入普通设置或诊断日志。
- Gmail 支持导入并校验 Google 桌面客户端 JSON，显示授权进度，区分配置缺失、拒绝授权、权限不足、API 未启用及旧凭据无法解密。修复浏览器预连接可能占住回调的问题。
- 应用启动、组件和授权诊断日志保留 14 天，设置页可打开或导出；日志只记录阶段、错误代码及异常类型。
- 升级后优先使用当前安装包中的组件，避免保留失效的旧运行路径。

安装 `ToolsTouch-Setup-0.2.0-win-x64.exe` 前请先退出旧版本。按当前 Windows 用户安装，无需管理员权限；升级保留本地资料和账户数据。安装包尚未签名，文件校验值见 SHA256SUMS.txt。

Gmail 仍需要有效的 Google 桌面 OAuth 客户端配置。本次未获得此配置，安装包未预置；可由发布者提供，或自行在 Google Cloud 创建后导入；未配置时无法完成首次登录或进入工作台。自动测试使用隔离的合成凭据和模拟授权响应，没有验证真实账号授权、模型额度或真实邮件发送。

验证：AgentHost 11 项、Core 全部测试和最终包 12 组 Windows 原生检查通过；随包 26,235 个文件哈希已校验。发布资产包含 Windows 测试结果与首次登录界面截图。
