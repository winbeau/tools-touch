# Tools Touch v0.3.1 测试版 · Windows 安装器

0.3 系列请下载 `ToolsTouch-Setup-0.3.1-win-x64.exe`。本次保留已发布的 v0.3.0，使用新的修复版本交付。

## 安装与升级

- Windows x64，当前用户安装，无需管理员权限。内置 .NET、Node／Pi 和 Python collector 运行环境。
- 默认安装到 `%LOCALAPPDATA%\Programs\ToolsTouch`。升级前退出应用；卸载保留 `%LOCALAPPDATA%\ToolsTouch` 下的用户资料。
- 恢复沿用 v0.2.2 的发布者 Google 桌面登录配置，普通用户无需自行导入客户端 JSON。
- 同时提供便携 ZIP、构建清单、安装器元数据、验收结果与 `SHA256SUMS.txt`。

## 修复与检查

修复 v0.3.0 中记录器折叠面板向只读属性回写导致的 WPF 启动错误。原生测试改为加载实际编译的主题资源，并遍历当前全部 11 个页面和详情子页；CI 增加 Windows 原生回归与证据输出。安装器构建增加完整生产运行依赖校验，安装测试支持从旧版 EXE 升级，并检查两个注册表视图和安装范围，避免影响既有注册安装。

修复 Windows 下备份、导出快照和隔离恢复的 SQLite 连接池保留文件句柄问题，临时数据库在操作结束后释放句柄；正式工作区继续使用原有连接池。回归覆盖备份／恢复完成后独占访问数据库文件。CI 同时补齐 Core 测试的 uv 环境和 Windows 报表测试的 UTF-8 读取。

已执行 Node 16 项、baoyan-cli 9 项、collector-host 8 项、C# Core 可执行回归、Windows x64 自包含构建、15,286 个便携包文件哈希和 Windows 原生 14 组检查。全新安装、重复安装修复、随包 Python 依赖导入、安装后桌面回归及卸载保留资料已通过；结果见 `INSTALLER-CHECK.json` 和 `WINDOWS-CHECK.json`。
