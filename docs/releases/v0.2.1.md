# Tools Touch v0.2.1 测试版

安装包内置发布者的 Google 桌面应用登录配置。普通用户下载后直接点击“使用 Google 登录”，无需创建 Google Cloud 项目或导入 JSON。每个人使用自己的 Gmail 作为应用账号及投递邮箱，个人登录凭据单独加密保存在本机。

登录页移除面向普通用户的开发者配置步骤；公开打包流程在缺少有效登录配置时直接拒绝构建。

已启用 Gmail API；Google Cloud 目前为 External / Testing，尚无测试用户，品牌资料和 Gmail 权限审核仍未完成，因此此版本仍是测试版。安装包内置配置不等于所有 Google 账号已经获得访问资格；若 Google 提示仅允许测试用户，需要发布者完成 Cloud 配置及相应审核。

保留 v0.2.0 的自动组件加载、进度条、多服务商配置、授权取消重试及诊断日志。升级前退出旧版本，安装不会删除本地资料。未进行真实邮件发送。

新增[应用主页](https://winbeau.github.io/tools-touch/)、[隐私政策](https://winbeau.github.io/tools-touch/privacy.html)及使用条款；为后续公开审核提供真实的数据使用说明。
