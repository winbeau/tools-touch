# Tools Touch v0.2.2 测试版

- 已连接的 Gmail 同时作为应用账号和发件邮箱，普通登录入口不会重复打开授权页；已保存的有效账号在再次连接和重启后复用。需要恢复失效授权时使用“重新授权 Gmail”。
- 增加“自动打开默认浏览器”开关，以及模型和 Gmail 的“复制登录链接”。关闭自动打开后，可在同一台电脑的浏览器中手动完成授权。
- 模型组件继承现有 HTTP/HTTPS 代理并启用运行时代理支持，本机 OAuth 回调保持直连；修复组件未使用代理导致的令牌交换连接失败；最终结果仍取决于网络及服务商账号权限。
- 修复重启后已保存模型账号被误显示为未连接：启动时恢复本地凭据状态，不依赖联网更新模型目录。
- 区分收到浏览器回调与凭据验证保存，补充嵌套错误分类；最终以程序保存凭据的结果为准。
- 首次登录页可直接打开诊断日志。

Google 项目已进入正式发布状态，但品牌和 Gmail 敏感/受限权限尚未通过验证，“未经验证的应用”提示及适用的用户配额仍可能出现。安装包不需要用户导入 JSON。本版保留测试标记，未发送真实邮件。

验证：14 项组件测试、C# 核心回归及 13 组 Windows 原生检查通过；OAuth 使用真实 SDK 配合模拟服务器响应，未以真实 OpenAI 账号完成端到端授权。
