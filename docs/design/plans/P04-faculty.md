# P04 导师目录采集、身份消歧与研究证据

状态：计划。前置：P01、P02；学院目录使用 P03。设计依据：[采集与推荐](../details/04-collection-recommendation.md)。

## 编码范围

Application Collection／Faculty／Research；Infrastructure 来源适配、SupervisorSnapshotImporter；collector-host 浏览器适配；Pi 研究提示模板与结构化输出；Desktop 导师详情及采集覆盖。

## 子步骤

1. 逐学院登记官方师资目录和覆盖范围，做分页／分类发现适配器与可重复网页 fixture。
2. 实现发现队列、CrawlItem 检查点、域名限流、页面变更检测、失败清单及覆盖统计。
3. 完成导师身份消歧、多个任职关系、曾用主页、公开邮箱与同名论文归属；歧义留待核实。
4. 结构化提取研究方向、本年／学位招生、名额、培养信息；所有声明引用原文定位。
5. 按最终确认的 Q3 来源策略增加评价／经验导入，保留未核实与冲突，去重转载。
6. 可选接入飞跃导师快照：结构／哈希检查、外部 ID 映射、上游时间保留，禁止覆盖用户备注。
7. 扩展论文证据与 Pi 分析，保存实际页码、AbstractOnly／Unreadable 和资料版本；导师库支持研究、比较和草稿入口。

## 验收

目录分页遍历、已发现但主页失败、未知总人数、同名异人、同人跨院、主页迁移、无邮箱导师保留、去年招生不沿用、本年学位区分、论文作者消歧、公开评价不当确证、恶意网页无法调用发送工具。断点恢复不重复抓取已提交页面。

## 退出条件与回退

3—5 所首轮学校对应学院有可审计的采集清单；“全量”注明已覆盖目录与例外。批次或来源失败可以局部重试；已有有效导师、历史分析及投递记录保留。若 Q3 未确认，公开官方目录与论文研究仍可实施，依赖社区访问的适配延后到选择明确后。
