# P06 邮件确认、发送核对与申请跟踪

状态：计划。前置：P02、P04；P05 推荐可作为入口但不是手动联系前置。设计依据：[邮件与投递](../details/05-mail-tracking.md)。

## 编码范围

Application Outreach／Tracking；Infrastructure Gmail／MIME／Persistence；现有 OutreachService／GmailService 迁移；Desktop 草稿编辑、确认对话框、申请详情；发送及回复测试。

## 子步骤

1. 绑定分析／资料／需求版本，Pi 创建本地草稿；恢复幂等与人工修改保留。
2. 实现发送预览、附件与内容哈希、一次确认消费、发送尝试事务和未决唯一约束。
3. 复核 Gmail 异常分类、取消语义、Unknown 锁定、重启恢复与原账号核对。
4. 回复按线程与邮件引用关联；跨线程歧义保留待核实，不让 AI 自动改正式申请阶段。
5. 实现 ApplicationCase／Event、官网提交回执、材料、优先级、下一步与提醒；区分申请／联系／窗口状态。
6. 加入记录器系统集合的字段编辑权限与只读发送状态，提供从表格进入详情的操作。

## 验收

旧发送回归继续通过；双击只发一次、确认后编辑失效、附件替换、过期确认、发送中断进入 Unknown、未查到不重发、回复去除自身消息、导入历史不触发发送、邮件 Sent 不自动表示官网 Submitted。

## 退出条件与回退

模拟环境完整走通研究→草稿→确认→回执／Unknown→跟踪；真实账号另记实际验收。真实发送只在用户对具体内容确认后执行。回退保留发送历史和未决尝试，任何脚本不通过重试业务状态补发邮件。
