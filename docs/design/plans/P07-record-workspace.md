# P07 表格记录器、自定义字段与全量导出

状态：计划。前置：P01；整合 P03—P06 实体与界面。设计依据：[记录器详细设计](../details/07-record-workspace.md)。

## 编码范围

Application RecordWorkspace／Fields／Views／ImportExport；Infrastructure 记录索引与 CSV／XLSX／ZIP 适配；Desktop 共用 RecordGrid、字段编辑器、过滤器、关联选择器、导入导出对话框。

## 子步骤

1. 将 P03 的共用表格基础扩展为内置 Collection 映射，统一记录 ID、字段类型和三种编辑权限。
2. 支持自定义表及文本／数字／日期／选择／复选／URL／关联字段，字段新增、重命名、归档和类型转换预览。
3. 实现单元格编辑、粘贴、按固定记录集合批量修改、Revision 冲突和可逆修改撤销；系统状态走业务命令。
4. 完成筛选 AST、排序、分组、列设置及保存／复制视图，关系字段可筛选和导航。
5. 实现导入映射／预览／去重／校验报告，系统实体通过领域服务写入，不能由导入制造发送成功。
6. 实现当前视图／当前表／按校分表／WorkspaceAll 导出，完整 ZIP 保存自定义字段、视图、关联、历史及可选附件。
7. 实现一致性导出快照、流式处理、进度与取消、文件哈希、导入恢复验证和关联 ID 重映射策略。

## 验收

创建“面试安排”自定义表并关联申请／导师，筛选／排序／重启恢复；批量冲突、撤销、受保护字段、人工更正证据；全量导出忽略 UI 分页／过滤；每校工作表重名、超长文本与拆表、公式前缀、全量 JSONL 往返、自定义字段与关系不丢失、取消不留半份成功文件。

## 退出条件与回退

项目可作为独立的结构化表格记录器使用，而不仅展示抓取结果。默认表和自定义表数据统一备份；导出记录数与快照一致。字段归档可恢复；类型变更失败保留旧值；恢复导入先落隔离工作区并校验。
