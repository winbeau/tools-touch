# P05 学院画像、背景统计与两级推荐

状态：计划。前置：P03、P04。设计依据：[采集与推荐](../details/04-collection-recommendation.md)。

## 编码范围

Core Recommendation／Profiles；Application StatisticsBuilder／EligibilityEvaluator／RecommendationService；Pi 结构化语义评估与解释；Infrastructure 推荐快照存储；Desktop 资料确认／推荐中心。

## 子步骤

1. 扩展 CV 背景事实确认及可选需求解析，区分硬约束和软偏好，保存版本与原文。
2. 实现 committee 声明及样本导入，按年度／项目／阶段／排名与论文口径分组，保存去重与缺失信息。
3. 实现 CohortStatistic，展示 985 分布、排名分位、论文分布、样本量及来源；小样本不输出伪精确门槛。
4. 完成三态资格评估、学院分项规则、可配置权重、未知值区间与稳定排序。
5. 完成导师全体基础候选、受预算语义评估、Top-K 论文深读；榜单明确比较范围。
6. 实现推荐输入物化快照、模型／提示／算法版本、理由／冲突／缺失项和新旧运行对比。
7. 整理首轮人工相关性样本，检查召回遗漏与解释正确性，再调整初始阈值／权重。

## 验收

所有硬条件冲突、未知资格、bar 分母、重复经验贴、已知零论文与未知、不同录取阶段、排名方向、权重归一、coverage 不足、模型无引用输出拒绝、同输入稳定、不同深读覆盖分组、资料变化生成新结果。推荐无数据时返回可解释空结果，不提供假名单。

## 退出条件与回退

用户可用同一资料获得学院与导师两级结果，查看分项、证据和适用范围。模型不可用时仍可查询历史结果／已完成基础评分，明确缺失语义层；切换算法版本不覆盖旧 run。
